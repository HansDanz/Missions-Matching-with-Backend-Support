# Internship-Application-Tracker
A full-stack web application for posting mission trip opportunities on a unified platform with CRUD functionality. Project done for Singapore Centre for Global Missions @ #HACK 2025

---

## Overview

This project helps missions agencies post mission trip opportunities on a unified platform and prospective missionaries apply for these opportunities.

---

## Tech Stack

Frontend:
- React

Backend: 
- Flask

Database:
- Firebase

Other Tools:
- Python
- JavaScript
- REST APIs
- Vibe Coded by Claude

---

## Features

User can apply for one of two account types: missions agency and missionary
Missions Agency:
- Add new mission trip opportunity
- Edit mission trip opportunity details
- Delete mission trip opportunity
- View applicants and contact details

Missionary:
- Indicate interest in opportunity
- Add contact details

## Architecture

React Frontend  
→ Fetch API requests  
→ Flask Backend  
→ Firebase Database

This architecture separates the frontend interface from the backend API and database layer.

---

## Steps to use
1. source env/bin/activate (for Mac) env/Scripts/Activate.ps1 (for Windows)
2. npm run install-all
3. pip install -r requirements.txt
4. npm run start
